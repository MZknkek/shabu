# Premium Suki Restaurant Management System

ระบบจัดการร้านอาหารสุกี้

## การติดตั้งและใช้งานบนเครื่องใหม่ (Setup for New Machines)

เพื่อให้โปรเจกต์นี้สามารถรันบนเครื่องอื่นได้ โปรดดำเนินการตามขั้นตอนดังนี้:

### 1. เตรียมฐานข้อมูล (Database)
1. ติดตั้ง **MySQL** (แนะนำให้ใช้ร่วมกับ XAMPP)
2. เปิด phpMyAdmin และสร้างฐานข้อมูลใหม่ชื่อ **`premium_suki`**
3. Import ข้อมูลตาราง (หากมีไฟล์ `schema.sql`) หรือสร้างตารางตามที่ระบุในคู่มือ

### 2. การตั้งค่า Backend
1. เข้าไปที่โฟลเดอร์ `backend/`
2. คัดลอกไฟล์ `.env.example` เป็น `.env`
3. เปิดไฟล์ `.env` และตั้งค่าคอนฟิกให้ตรงกับเครื่องของคุณ (DB_USER, DB_PASSWORD, ฯลฯ)
4. ติดตั้ง Dependencies:
   ```bash
   npm install
   ```
5. รันเซิร์ฟเวอร์:
   ```bash
   npm start
   ```
   (เซิร์ฟเวอร์จะทำงานบนพอร์ต `3000`)

### 3. การตั้งค่า Frontend
1. เปิดโฟลเดอร์ `frontend/` ด้วย VS Code
2. ใช้ส่วนขยาย **Live Server** เพื่อเปิดไฟล์ `index.html` ของแต่ละหน้า (Admin หรือ Customer)
3. **ข้อควรระวัง**: ตรวจสอบไฟล์ `app.js` ในโฟลเดอร์ `frontend/` ว่ามีการกำหนด URL ของ API ตรงกับเครื่องของคุณหรือไม่ (ปกติคือ `http://localhost:3000`)
